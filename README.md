# CookingAI.app 🍳

Cooking AI — мобільний Android-застосунок для розумного підбору рецептів,
аналізу продуктів користувача та формування списку покупок.

## Ідея

Застосунок допомагає користувачу пройти повний шлях:

**Що я хочу приготувати → Що в мене вже є → Що потрібно докупити → 
Де це знайти → Який варіант покупки найкраще відповідає моїм критеріям.**

## Основні можливості

- ведення списку продуктів, які є вдома;
- пошук рецептів за тегами;
- пошук страв природною мовою;
- AI-рекомендації рецептів;
- врахування алергенів та харчових обмежень;
- визначення відсутніх інгредієнтів;
- автоматичне формування списку покупок;
- пошук необхідних продуктів у магазинах;
- порівняння варіантів покупки за ціною та відстанню.

## Використання AI

Штучний інтелект використовується для:

- розуміння запитів природною мовою;
- персоналізованого підбору рецептів;
- аналізу наявних продуктів;
- підбору альтернативних інгредієнтів;
- врахування харчових обмежень;
- пояснення рекомендацій.

AI не генерує інформацію про актуальні ціни або наявність товарів.
Такі дані повинні надходити із зовнішніх API або інших актуальних джерел.

## Архітектура

Застосунок використовує багаторівневу архітектуру:

- Presentation / UI Layer
- Domain Layer
- Data Layer
- AI Service
- External Store / Product API
- Maps / Location Service
